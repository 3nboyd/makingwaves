Workflow

A booth-friendly path from setup to showtime.

The site is designed so you can prep quickly in a green room, then shift to a clean stage display when the set starts.

01

Grant secure-device access

GitHub Pages serves over HTTPS, so the browser can prompt for camera and audio access. Once granted, labels and device switching become available.

02

Route your DJ master bus

Feed the browser from a loopback channel, virtual interface, or routed audio bus so the visuals react to the same signal the audience hears.

03

Tune the response live

Adjust effect intensity, trail decay, audio sensitivity, and segmentation threshold until the body effects feel tight rather than noisy.

04

Go fullscreen and capture

Use fullscreen for the stage wall, enable wake lock where supported, and record the rendered canvas plus selected audio input straight from the browser.

Deploy Directly

Drop the repo onto GitHub Pages and perform from a secure static URL.

There is no backend dependency to provision. Push the files, enable Pages, and use the published HTTPS URL for input permissions, fullscreen visuals, and local recording.
